# 混煤指标精准预测算法调研与实施路线

> 2026-07-04。深度调研（5 路检索 / 20 源 / 97 条候选结论 / 25 条经 3 票对抗验证，22 存活 3 否证），
> 结合本仓库代码事实（`optimizer.rs` 纯 LP、`predict.rs` OLS 回归、Clarabel 0.10）。
> 目标：回答"哪些指标能继续线性加权、哪些必须换算法、非线性怎么进求解器、要采什么数据"。

> **实施状态（2026-07-17）**：阶段 0 与阶段 1 已落地，并完成第一版阶段 2。
> 当前算法支持逐指标判定规则、Hard/Soft/Advisory、G/CSR 可选模型复核、
> 交叉验证与训练域门控，以及岩相全方差复验和迭代修复。没有启用校正模型或
> 精确岩相输入时，系统保留线性代理并明确标记为估算，不阻断基础求解。
> 高斯 G、CSR 二次/地质特征与信赖域 SLP 仍属于后续算法阶段。

## 0. 结论速览

| 指标 | 混配行为 | 推荐算法 | 所需单煤数据 | 实施复杂度 |
|---|---|---|---|---|
| S 硫分 | 线性（实测平均误差 0.01pp） | 保持 LP 加权 | 现有 | 无需改动 |
| A 灰分 | 线性（0.03pp） | 保持 LP 加权 | 现有 | 无需改动 |
| M 水分 | 线性（0.03pp；三煤 0.12pp） | 保持 LP 加权 | 现有 | 无需改动 |
| V 挥发分 | 近线性（平均 0.46pp，最大 0.83pp） | 保持 LP 加权 + 约束留 ~1pp 余量 | 现有 | 低 |
| G 粘结指数 | **显著非线性**：两煤误差均值 5.31%/最大 12.60%，三煤 8.32%/16.30%，加权值系统性**高估**实测约 11% | 加权值 + 高斯修正项模型（结构见 §2），系数用自有回填数据重拟合；拟合前先按偏差幅度收紧约束 | 现有 + 混煤实测 G 回填 | 中 |
| Y 胶质层 | **文献未覆盖**（未决问题） | 暂保持线性 + 回填实测 Y 自行验证偏差 | 混煤实测 Y 回填 | 低 |
| petro 岩相 | 线性加权在数学上**不成立**；正确算法是直方图合成 + 全方差定律，σ² 是配比的**凹二次型（反凸约束）** | 求解后精确计算 σ + 凹口检测，违约则收紧迭代重解（§3）；**不能**直接进 SOCP | 反射率直方图 + 镜质组含量 + μ/σ（MT/T 507 化验单自带） | 中-高 |
| CSR 焦炭热强 | 文献模型一致结论：**出了拟合煤域一律失效，必须本地重拟合** | 现有 `predict.rs` 回填回归路线方向正确；扩特征（Vdaf、灰化学、成煤期）、扩回填指标 | 混煤实测 CSR（已有闭环）+ 可选灰成分 | 已有骨架 |

三条被对抗验证**否证**的假设（避免踩坑）：

1. ❌ **"岩相 σ 约束可以直接编码进 Clarabel SOCP"（0-3 否决）**。σ²_mix 对归一化权重是凹二次函数，σ²≤c 是反凸约束，凸锥求解器无法直接表达；且岩相权重 y_j 对质量配比 x_j 还是分式变换。只能走"求解后校验 + 迭代"或带信赖域的 SLP。（此前项目内部曾假设 SOCP 可行，本次调研纠正。）
2. ❌ "双线性问题 LP/SOCP/SDP 松弛界相等"（1-2）——SOCP 升级收益的论断不可引用。
3. ❌ "GB/T 6948 + GB/T 15591 + GB/T 4000 三标准构成岩相口径基础"（0-3，可能涉及版本/替代关系错误）——引用具体标准号前需另行核实现行版本。

## 1. 线性可加指标：S / A / V / M（维持现状）

《选煤技术》2025 年实测研究（两煤及三煤参配、同口径）逐项核对：灰分/水分/硫分加权平均误差
平均 ≤0.03pp、最大 ≤0.10pp；挥发分平均 0.46pp、最大 0.83pp；三煤时 M/S 出现非线性特征但绝对
误差仍小（M 0.12/0.21pp）。结论：这 4 项继续留在 LP 线性约束中是安全的，V 建议在约束上留
~1pp 工程余量。【3-0 通过】

**口径警告（未决）**：上述实验均在统一基准下混配。干基/空干基/收到基混算的误差文献未单独量化。
本项目现状是"按收到基质量加权干基指标"（`optimizer.rs` 直接加权 props），池内 M=11 与 M=23 并存
时数学上有偏。短期靠录入口径纪律（统一收到基或统一干基），长期在 Coal 上加 basis 字段做换算。

## 2. G 值：必须修正的第一优先非线性

- **偏差方向与幅度**：加权 G 对实测 G 拟合斜率两煤 0.989 → 三煤 0.892，即煤种越多加权值越
  **高估**实测（约 11% 系统偏差）。这正是"LP 解顶着 G 下限贴边 + 加权高估"叠加成实配 G 不合格
  的机制——当前代码的风险点。【3-0 ×3】
- **可实施修正模型**（《选煤技术》2025，R²=0.927 vs 纯加权）：

  ```
  Ĝ = a0·G_加权 + a1·exp(−(Vf−b1)²/(2c1²)) − a2·exp(−(Vps−b2)²/(2c2²))
  ```

  其中 Vf/Vps 为肥煤/贫瘦煤挥发分的加权贡献值。原文系数（a0=0.993, a1=10.767, a2=0.636,
  b1=−2.241, b2=−1.191, c1=5.623, c2=40.163）拟合自磁西煤田，**属场地特定，结构可借鉴、
  系数必须用吕梁自有数据重拟合**。
- **实施顺序**：
  1. 立即：G 下限约束加"收紧系数"（如 spec.min × 1.05 或 +3 个点），把 11% 高估的风险兜住；
  2. 回填闭环扩项：历史方案除 CSR 外**同时回填混煤实测 G**（化验单上就有，零额外成本）；
  3. 样本够后拟合上式（或先拟合更简单的 Ĝ = k·G_加权 + b），把修正模型接进求解后校验环（§3）。

## 3. 岩相：正确算法 + 它为什么进不了凸求解器

### 3.1 正确的混煤岩相计算（当前代码的线性加权是错的）

混煤反射率直方图 = 单煤直方图按**镜质组含量修正配比**加权合成：

```
y_j = V_j·x_j / Σ_k(V_k·x_k)     （V_j = 煤 j 的镜质组体积含量; 仅当各煤 V 相同才退化为 x_j）
直方图_mix(bin i) = Σ_j y_j · 直方图_j(bin i)
μ_mix = Σ_i c_i·w_i;   σ²_mix = Σ_i c_i²·w_i − μ_mix²     （c_i = bin 中值, w_i = 合成频率）
```

即全方差定律：σ²_mix = Σ y_j(σ_j² + μ_j²) − μ_mix²。单种煤分布近似正态。
【《矿业科学学报》2017 式(6)(7)(9)(10)，3-0 ×2；验证 agent 对 σ² 二次型性质做了数值复核】

**求解器结论**：σ² 对 y 是凹二次函数 → σ²≤c 是反凸约束，**不能**表达为 SOCP 锥约束；
y 对 x 又是分式。唯一工程可行路线是把 σ 计算放在**求解后**（闭式、微秒级），违约时收紧重解。

### 3.2 工程规则（实测支持，本钢 40kg 焦炉）

- σ<0.1 判单一煤层煤；0.1~0.15 简单混煤；>0.2 多凹口混煤。当前 master 的 `petro≤0.15` 约束
  语义上对应"配合煤 σ 上限"，方向合理，但**混合值必须按 §3.1 算而不是线性加权**。
- 直方图**凹口落在 1.2~1.5（主焦煤区间）损害焦质**；回补凹口使分布趋近正态，实测 CSR
  48.92%→54.27%（+5.35pp，注意该对比含混杂变量，量级外推谨慎）。【3-0 ×2】
- **防掺假价值（对数据护城河战略重要）**：三个煤样 G 值 80/80/82、Y 16/17/16、Vdaf 几乎相同，
  常规 8 项指标完全无法区分，反射率分布图直接判出其中两个是带凹口的掺混煤。**直方图是
  8 项常规指标之外唯一能验供煤真伪的数据**。【3-0】
- 分布形状比 (μ,σ) 两个数携带更多预测信息（多峰性；SOM 分类特征显著改进焦质回归）——
  **落库时存完整 bin 向量**，不要只存 σ。【3-0 ×2】

### 3.3 数据采集口径

MT/T 507—2019 要求煤岩化验报告给出反射率分布直方图、算术平均值，且均值/标准差以单个测值
计算——**标准煤岩化验单天然包含所需全部输入**（直方图 + μ + σ；镜质组含量在煤岩定量报告中）。
无需发明新化验项目，采集动作就是"要煤岩化验单原件而不是只抄一个数"。【2-1，medium——
执行前拿一张真实化验单核对一遍】

## 4. CSR：文献模型全部不可移植，回填回归是正解

约 200 篇文献的系统综述（Fuel 219, 2018）核心结论：**每个 CSR/CRI 模型的效度局限于其拟合
煤域，跨煤域必须重拟合**。这从文献层面确认了本项目"实测回填 → 本地回归"（`predict.rs` +
blend_history.csr_measured 闭环）是行业公认的正确路线。文献模型的价值是**特征选择与函数形式
先验**：【3-0 ×2】

- **汾渭专利 CN114880864B**（两段回归）：M40 = f_linear(Vdaf, G+G′, Y, ρ)；CSR = 二次(M40) −
  5.7(MCI−δ)。两个启示：① CSR 对中间量是**二次**的，`predict.rs` 纯线性可能欠拟合，样本够后
  试二次项；② G′ 是**成煤期校正**（二叠 +2 / 石炭 +5 / 侏罗 −7 / 白垩 −9）——常规指标完全相同
  的煤因成煤期不同焦质不同，**master 应记录矿的成煤期/煤田元数据**（mines 表已有省市，加一列即可）。
- **Tata Steel 灰化学路线**：CRI = −1753·MBI² + 6541·MBI − 3476（R²=0.80），CSR 对 CRI 线性。
  若将来采集灰成分（SiO₂/Al₂O₃/CaO/Fe₂O₃…），MBI 是现成特征。可选项，非必须。
- **样本量**：文献未给出工程可用的最小回填样本数（未决问题）。`predict.rs` 的 n≥7 只是代数
  下限；实践建议 R² 与留一交叉验证误差达标前，预测值只展示不进约束。

## 5. 非线性进优化器：两阶段工程方案

文献共识：**不要把非线性硬塞进凸求解器**。【3-0 ×3】

**阶段一（推荐立即采用）："LP 出解 → 非线性校验 → 收紧重解"环**

```
solve LP (现有线性代理约束)
  → 用精确/修正模型评估: σ_mix(直方图), Ĝ(高斯修正), CSR(回归)
  → 全达标? 输出(附"校验后指标")
  → 有违约? 收紧对应线性代理界(如 G_min += 违约量×1.5; σ 超标 → 收紧 petro 代理或禁用凹口贡献煤)
  → 重解, 上限 3~5 轮(每轮 <1ms, 总耗时仍毫秒级)
```

这是文献验证的"松弛 + 可行性修复"模式，显式为了避免引入 NLP 求解器。实施位置：
`optimizer.rs` 外层加一个迭代包装，`solve_json` 接口不变。

**阶段二（仅当阶段一收敛质量不够）：信赖域 SLP + 多起点**

裸 SLP 在配料类双线性问题上不可靠（子问题可能无界/巨步），必须信赖域(∞范数步长界 +
filter/merit 接受逻辑) + 随机多起点。收益：对 11 个工业配料实例，相对 FilterSQP/IPOpt/Baron
期望提速 20~863 倍——即在现有 Clarabel LP 上加外环即可，不用换求解器。【3-0 ×3，注意该
基准早于 Gurobi 非凸双线性功能，跨代际对比部分过时】

**兜底措施（阶段零，一天工作量）**：给 spec 加可配置安全余量（收紧系数），至少覆盖 G 的
~11% 高估和"LP 解必然贴边"的双重风险。这在任何模型上线前就该有。

## 7. 未决问题（诚实清单）

1. **Y 值可加性**：无存活文献结论。处置：暂保持线性，回填实测 Y 自行验证（这正是回填扩项的用途）。
2. **干基/收到基混算误差量化**：文献均在统一口径下实验。处置：录入口径纪律 + 长期加 basis 字段。
3. **σ 约束的凸内逼近**是否存在（割线上界/分段线性化），还是只能校验迭代——阶段一跑起来后再评估。
4. **CSR 回归最小样本量**：无文献数字。处置：交叉验证达标前预测值不进约束。
5. GB/T 标准现行版本号需在写用户文档前另行核实（相关 claim 被否证）。
